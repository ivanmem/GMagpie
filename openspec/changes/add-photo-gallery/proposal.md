# Proposal: add-photo-gallery

## Why
Пользователь хочет просматривать папку с фото на весь экран с апскейлом в нативном
качестве: эффекты GMagpie должны получать исходные пиксели файла, а не размытый захват
вьюера. Существующий механизм «открыть фото во вьювере + масштабировать окно» нарушает
это (вьювер сначала сам вписывает фото в окно). Нужен режим галереи/слайдшоу поверх
имеющегося пайплайна с прежним выбором эффекта-групп.

## What Changes
- Новый режим «фото-сессия»: картинка декодируется из файла в `ID3D11Texture2D`
  нативного размера (`PhotoFrameSource`) и подаётся в штатную эффект-цепь; на экран
  выводится только результат апскейла (letterbox по аспекту через `ScalingType::Fit`).
- Галерея: рекурсивный обход папки, листание стрелками/колесом, автолистание раз в
  N секунд со сбросом таймера при ручном листании, пауза (Space), выход (Esc).
- Быстрая клавиша Num6 (Shift+Num6 назад) — цикл по апскейлерам (Bicubic → Lanczos →
  Jinc → NIS …) на живой сессии, без изменения сохранённых профилей.
- Выбор эффекта-группы — как в оригинале (тот же список ScalingModes; запуск сессии
  принимает индекс режима, по умолчанию — из профиля по умолчанию).
- v1-управление через CLI: `GMagpie.exe --gallery <папка> [--interval сек] [--mode имя]`.
  Показ идёт в «лёгком режиме» (отдельная группа единственного экземпляра, соседствует с
  обычным GMagpie). Главная: карточка «Фотогалерея» (интервал, папка, «Продолжить», прогресс «N / M»);
  в показе - предзагрузка соседней страницы и удаление текущего файла в корзину (Delete).
  XAML-карточка на HomePage — следующий итератив (вне рамок этого изменения).

## Out of Scope
- Миниатюры/браузер превью; HDR-фото (вход всегда SDR-конвертация в sRGB/BGRA8);
  зум/кроп; веб-интерфейс; изменение формата профилей; XAML UI галереи.

## Impact
- Affected specs: `photo-gallery` (новый capability).
- Affected code:
  - `src/GMagpie.Core`: новый `PhotoFrameSource` (+.h), `Renderer` (выбор источника,
    ребинд цепи, `SrcRect`), `ScalingWindow`/`ScalingRuntime` (passthrough
    `RequestPhotoFile`), `FrameSourceBase` (виртуальный `RequiresRebind`),
    `ScalingOptions` (`PhotoSessionOptions`).
  - `src/GMagpie`: `ScalingService` (запуск/остановка фото-сессии, stage-окно,
    рестарт эффектов), новый `GalleryService` (плейлист/таймер/хуки/цикл апскейлеров),
    `App.cpp` (CLI).
  - `.vcxproj`/`.filters` обоих проектов.
- Риски: поведение при смене foreground (Mitigation: SetForegroundWindow stage);
  корректность `_ResizeEffects()` на новой фототекстуре (главная новая логика);
  недоступность апскейлера на GPU → цикл содержит только HLSL-эффекты с `CanScale()`.
