# GMagpie v0.1.0

Первый выпуск GMagpie - полноэкранной фотогалереи с апскейлом фото.

## Галерея

- Открытие папки (с подпапками) с главной страницы или командой `GMagpie.exe --gallery <папка> [--interval сек]`; «Продолжить» и счётчик «N / M».
- Открытие одного файла вместе с соседями по папке: `GMagpie.exe "<файл>"`, пункт в контекстном меню Проводника и «Открыть с помощью».
- Сначала показывается оригинал, затем - результат апскейла, поэтому под нагрузкой на видеокарту экран не чернеет.
- Апскейл фото меньше экрана: RTX VSR, RTX VSR + Deblur, ACNet. Выбор - в меню по правой кнопке мыши или Num6.
- Анимированные GIF и WebP проигрываются, апскейл и сравнение с оригиналом работают на каждом кадре.
- «В избранное» (Insert или меню) переносит фото в `..\favorite`; папку можно сменить на главной странице.
- Delete переносит фото в корзину.

## Интерфейс

Из интерфейса Magpie убрано всё, что не нужно галерее: профили окон, настройки масштабирования, запуск масштабирования окон и сенсорный ввод.

## Известные ограничения

- RTX Video работает только на видеокартах NVIDIA RTX.
- «Продолжить» после открытия одного файла сканирует папку вместе с подпапками.
