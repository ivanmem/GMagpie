# GMagpie Experimental v0.1.0

Первый выпуск GMagpie: полноэкранная фотогалерея поверх эффект-цепи масштабирования. Остальные возможности (OKLab, DLSSNR, параметры, захват и вывод) унаследованы от базы 0.6.12.

## Фотогалерея

- Запуск: `GMagpie.exe --gallery <папка> [--interval сек] [--mode "имя режима"]`; папка просматривается вместе с подпапками. Или карточка «Фотогалерея» на главной: интервал, выбор папки, «Продолжить», прогресс «N / M».
- Одно фото: `GMagpie.exe "<файл>"` или `--gallery "<файл>"` открывает файл и его соседей по папке (без подпапок). Если показ уже идёт, второй запуск с файлом открывает фото в нём.
- Контекстное меню Проводника «Открыть в галерее GMagpie» и запись в «Открыть с помощью»: переключатель на главной или `--register-shell` / `--unregister-shell` (только HKCU, программой по умолчанию не становится).
- Управление: стрелки, колесо, Home/End, Space - пауза, Delete - в корзину, Esc/F11 - выход, Num6 - выбор апскейлера (в том числе RTX Video VSR). Сравнение в фото-сессии выключено.
- Фото декодируется в нативном размере (с учётом EXIF-поворота) и идёт в штатную эффект-цепь; на экран выводится результат с сохранением пропорций.
- Показ идёт в «лёгком режиме»: отдельная группа единственного экземпляра, без глобальных хоткеев и проверки обновлений; живёт рядом с обычным GMagpie.
- Отзывчивость: страница, которую уже пролистали, не тратит время GPU (не дольше 200 мс подряд); запрос страницы идёт первым, строка состояния обновляется отложенно. В логе для каждой страницы: «Фото: загрузка … мс, цепь и отправка … мс».

## Имя

Приложение называется GMagpie (`GMagpie.exe`). Папка данных осталась прежней: `%LOCALAPPDATA%\Magpie\config\v4e`, настройки сохраняются.

## Известные ограничения

- Форматы: JPEG, PNG, BMP, GIF, TIFF, WebP; HEIC/HEIF/AVIF - если в системе есть декодеры.
- Двухфазный показ («сразу без апскейла, затем дорисовать») не реализован: на перегруженной видеокарте новая страница ждёт цепь эффектов.
- «Продолжить» после открытия одного файла сканирует папку вместе с подпапками.
