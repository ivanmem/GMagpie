# Следующая и опубликованная версии

## Следующая версия

Локальный кандидат - **GMagpie Experimental v0.1.0** (первый выпуск GMagpie), тег `v0.1.0-experimental` подготовлен, загрузка и публикация не выполнялись. К базе 0.6.12 (OKLab, DLSSNR, окно параметров, исправления захвата и вывода) добавлена полноэкранная фотогалерея. Сборка и результаты приёмки указываются в манифесте сборки и записи проверки кандидата.
