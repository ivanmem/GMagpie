<h1 align="center">GMagpie</h1>

**Версия 0.1.0** · [Скачать](https://github.com/ivanmem/GMagpie/releases/latest) · [Заметки к выпуску](docs/RELEASE_NOTES_v0.1.0-experimental.md)

GMagpie - полноэкранная фотогалерея для Windows с апскейлом фото через RTX Video и другие эффекты. Это неофициальный форк [Blinue/Magpie](https://github.com/Blinue/Magpie): галерея берёт его цепочку эффектов, но подаёт в неё исходные пиксели файла, а не захват окна просмотрщика.

## Возможности

- Папка (вместе с подпапками) открывается карточкой на главной странице или командой `GMagpie.exe --gallery <папка> [--interval сек]`. В карточке есть «Продолжить» и счётчик «N / M».
- Одно фото: `GMagpie.exe "<файл>"` открывает файл и его соседей по папке. Повторный запуск с файлом открывает его в уже идущей галерее.
- Фото декодируется в нативном размере с учётом EXIF-поворота. Сначала на экране появляется оригинал, затем - результат апскейла.
- Апскейл включается для фото меньше экрана. Апскейлеры: RTX VSR, RTX VSR + Deblur (для мыльных исходников), ACNet.
- Анимированные GIF и WebP проигрываются с апскейлом каждого кадра.
- «В избранное» переносит фото в папку `..\favorite` рядом с ним; папку можно сменить на главной странице.
- Пункт «Открыть в галерее GMagpie» в контекстном меню Проводника и запись «Открыть с помощью» включаются переключателем на главной (только для текущего пользователя, права администратора не нужны).

## Управление

| Клавиша | Действие |
|---|---|
| Стрелки, колесо мыши, Home/End | листать |
| Space | пауза слайд-шоу |
| Правая кнопка мыши или Num6 | меню: апскейлер, избранное, удаление |
| Insert | в избранное |
| Delete | в корзину |
| Esc, F11 | выход |

## Установка

1. Скачайте `GMagpie-Experimental-x64.zip` со страницы [выпусков](https://github.com/ivanmem/GMagpie/releases).
2. Распакуйте весь архив в новую папку.
3. Запустите `GMagpie.exe` и откройте папку с фотографиями.

Настройки хранятся в `%LOCALAPPDATA%\Magpie\config\v4e`.

## Требования

- Windows 10/11 x64, видеокарта с DirectX 11.
- Апскейлеры RTX Video - только на видеокартах NVIDIA RTX с актуальным драйвером.
- Форматы: JPEG, PNG, BMP, GIF, TIFF, WebP; HEIC, HEIF и AVIF - если в системе установлены их декодеры.

## Сообщить о проблеме

Приложите к [обращению](https://github.com/ivanmem/GMagpie/issues) журнал из папки `logs` рядом с программой, модель видеокарты, версию драйвера, размер фото и шаги воспроизведения.
